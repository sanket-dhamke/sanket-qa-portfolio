How to run

cd ui
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
playwright install chromium
pytest -m smoke
pytest -m sanity
pytest -m regression
pytest -m ui --alluredir=reports/allure-results
allure generate reports/allure-results -o ../docs/reports/allure-ui --clean --single-file --name "UI automation"

Allure report

Allure report — static export (suites, steps, status, screenshot attachments). Raw results stay in ui/reports/allure-results/.

AI-based agent

In the lab console, “Check UI sanity” is a keyword route to the suite catalog (handler:run_suite, layer ui). Pages replays fixtures. This tree is the Playwright implementation. Details: ui/AI-AGENT.md, ui/SKILLS.md, and .cursor/skills/ui-automation/SKILL.md.
