About this sample

I am Sanket Dhamke, a Lead SDET with 12 years in QA: UI automation, API automation, performance testing, and hybrid agentic QA (rules and a cited knowledge base first; a model never invents numbers). LinkedIn.

This repository is an original portfolio sample of a hybrid keyword/rule intent router plus a pytest API (and light UI) framework. The operations console speaks open-source DataHub (datahubproject.io): ingestion sources, recipe YAML, aspects, datasets, lineage, datahub-gms / consumers / actions. It is a fictional demo tenant. Charts, asset counts, and ingest runs are simulated. There is no live cluster behind the page.

Original portfolio sample of a hybrid router + API test framework. Not affiliated with any prior employer product.

What this is not

  • Not a hosted DataHub cloud and not a scrape of any private knowledge base.
  • Not an LLM demo. The router is keyword-based. If “AI” is off, handlers still answer from fixtures.
  • Not a claim that a model produced the CPU, restart, or asset numbers you see.
