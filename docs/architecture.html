Hybrid router

A question hits a keyword/rule table. The first match wins. That is the whole router. There is no embedding index and no hosted model in this sample. If a model were plugged in later, it would only be allowed to rephrase text that a handler or the KB already produced — a model never produces a number.

1. Intent router Ordered keyword rules in agent/router.py. Vanilla JS port for GitHub Pages.
2. Handlers Read fixture JSON: cluster, metrics, ingestion, RCA, alerts, app config. Return measured values only. Chip: Handler · fixtures only.
3. KB + API exec Catalog of DataHub GraphQL/REST entries. Explicit questions (login, alerts, /health) run the mock API and print status + body. Cite chip: Knowledge base · cited catalog.
4. Suite executor smoke / sanity / regression (API, UI, performance layers). Pages replays agent/fixtures/suites.json; pytest still owns the live checks. Chip: Suite catalog · pytest markers.
5. Rule RCA agent/rca_engine.py fires or skips named rules. Exit 137 is SIGKILL; memory pressure only when last_reason=OOMKilled. Skipped rules are part of the diagnosis (probe vs OOM, heap already set).
6. App verdict Pods + RCA + smoke + sanity, then the agent asks before full regression. Yes runs it; no skips.
7. Fallback If nothing matches, a deterministic refusal. No invented CPU, assets, or passwords.

Visible source field

Every answer carries source plus a kind chip so you can see which path ran:

  • handler:pod_status / handler:perf_rca — fixtures and the rule engine. A model never picks the tool.
  • kb:graphql.createIngestionSource — cited catalog file, no number invented.
  • handler:run_suite:sanity:ui — pytest marker catalog replay, with Symptom / Cause / Fix on fails.
  • fallback:deterministic — no match, no hallucination.

The console paints those chips next to the reply. pytest in tests/test_routing.py asserts the canned questions take different sources — no network.

Where the model is not

The honest answer to “is this an AI project?” is nuanced. A model is optional, and it is only allowed to rephrase text a handler or the knowledge base already produced. If it is off, the same numbers still return.

Does not choose tools A keyword table in agent/router.py picks the path. First match wins. Inspectable, instant, free, same answer every time. Fixing a miss is one table line, not a prompt rewrite.
Does not collect metrics Handlers read fixture JSON (cluster, metrics, ingestion, alerts). CPU and memory are percent of each pod’s configured limit, not of node capacity. A pod with no limit gets no percentage.
Does not set RCA Named rules in agent/rca_engine.py fire or skip. Exit 137 is SIGKILL; memory pressure only when last_reason=OOMKilled. Severity comes from the rule, not from prose.

The console Tools tab lists the catalog. Cluster tools never call GraphQL. gms_heap reads datahub-gms java opts from the cluster fixture — it does not query GMS. Tools marked GMS GraphQL (catalog_stats, search_latency, list_incidents) are the ones that need the metadata fixture.

DataHub vocabulary in this lab

Components: datahub-gms, datahub-mae-consumer, datahub-mce-consumer, datahub-frontend, datahub-actions. Ingestion uses recipe YAML (type: postgres / type: oracle), pipeline name, schema_pattern / table_pattern, sink datahub-rest to GMS. GraphQL: listIngestionSources, createIngestionSource (JSON-encoded recipe, executorId), createIngestionExecutionRequest. Aspects such as schemaMetadata and upstreamLineage show up in the fake run log. Public docs: Postgres source.

The in-browser console is a JS port of the Python router so GitHub Pages can run without a Python host. Python remains the source of truth.
