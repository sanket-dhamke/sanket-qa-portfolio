API automation

pytest + requests (FastAPI TestClient) against a bundled mock DataHub-like GraphQL/REST in api/app.py. It is not a real DataHub cloud. Tests cover health, login (emuser/empass), incidents, list ingestion sources, asset counts, create source from YAML, and poll execution until SUCCESS.

Folder map

agent/          router, handlers, KB, fixtures, recipes
api/app.py      mock GMS: /health /config /logIn POST /api/graphql
agent/fixtures/suites.json   smoke / sanity / regression catalog
tests/test_routing.py     no-network source assertions
tests/test_hybrid_agent.py  login, suites, alerts, capacity, verdict
tests/api/test_login.py   smoke login + sanity incidents
tests/api/test_ingestion.py  sanity list / counts / YAML / poll
tests/ui/                 Playwright against this site
docs/reports/             checked-in pytest-html snapshot

How to run

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pytest -m "smoke or sanity" tests/test_routing.py tests/api \
  --html=docs/reports/pytest-report.html --self-contained-html
# UI (optional)
playwright install chromium
pytest -m ui tests/ui

Markers: smoke, sanity, regression, ui. Ask the console agent to run those suites; it replays the catalog and prints RCA on failures. Domain asserts: HTTP status, JSON shape, fixture asset counts, durationMs from the mock execution, elapsed time under 1s.
